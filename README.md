# Analisis Data Pengeluaran Operasional untuk Mendukung Efisiensi Anggaran

## Deskripsi Proyek
Proyek ini menganalisis data pengeluaran operasional untuk membantu mengidentifikasi pola biaya, mengevaluasi penggunaan anggaran, dan memperkirakan pengeluaran pada bulan berikutnya.

## Tujuan
- Menganalisis tren pengeluaran operasional.
- Mengidentifikasi kategori dengan selisih anggaran terbesar.
- Mengetahui pola pengeluaran berdasarkan departemen dan waktu.
- Memprediksi pengeluaran bulanan menggunakan regresi linear.
- Menyusun rekomendasi berdasarkan hasil analisis.

## Teknologi
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Metode Analisis
1. Data Understanding dan Data Cleaning
2. Analisis Deskriptif dan Visualisasi
3. Analisis Diagnostik
4. Analisis Prediktif
5. Evaluasi Model
6. Interpretasi dan Rekomendasi

## Dataset
Dataset yang digunakan merupakan data simulasi untuk keperluan pembelajaran dan bukan data keuangan perusahaan nyata.

## Cara Menjalankan
Buka file `analisis_pengeluaran_operasional.ipynb` melalui Google Colab, lalu jalankan setiap sel secara berurutan dari awal hingga akhir.

## Keterbatasan
Hasil analisis dan prediksi bergantung pada data simulasi. Prediksi merupakan estimasi, bukan kepastian, sehingga perlu dievaluasi sebelum digunakan untuk mengambil keputusan.
